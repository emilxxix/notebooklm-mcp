# 🌸 ทริปเชียงใหม่ 26–29 ก.ค. 2569 — Trip Planner

เว็บแอพวางแผนเที่ยว + บันทึกค่าใช้จ่าย ไฟล์เดียวจบ (`index.html`) ไม่ต้องติดตั้งอะไร
เปิดในเบราว์เซอร์ได้เลยทั้งมือถือและคอมพิวเตอร์ ข้อมูลบันทึกอัตโนมัติในเครื่อง (localStorage)

## ฟีเจอร์

- 📅 **แพลนรายวัน 4 วัน 3 คืน** — จัดเรียงที่เที่ยวตามโซน (วันที่ 1–2 เชียงดาว ค้างคืนบนดอย → ขากลับแวะแม่ตะมาน/ม่อนแจ่ม → วันที่ 3 ดอยสุเทพ/นิมมาน → วันที่ 4 เมืองเก่า/ของฝาก) จะได้ไม่ขับรถวนไปมา สลับลำดับ/ย้ายวัน/เพิ่ม/ลบได้ ติ๊ก ✓ เมื่อไปมาแล้ว
- 💰 **บันทึกค่าใช้จ่าย** — แต่ละรายการเก็บ งบที่ตั้งไว้ / จ่ายจริง / จองผ่านที่ไหน (สายการบิน, Agoda ฯลฯ) / โปรโมชั่นที่ใช้ / วิธีจ่าย (เงินสด, บัตรเครดิต, ผ่อนบัตร 0% พร้อมจำนวนเดือน)
- 📊 **สรุปทริป** — งบรวม vs ใช้จริง, กราฟรายหมวด, ยอดผ่อนบัตรต่อเดือน, นับถอยหลังวันเดินทาง
- 🌙 รองรับโหมดมืดอัตโนมัติ · 📤 สำรอง/กู้คืนข้อมูลได้ (คัดลอกข้อความ, แชร์เป็นไฟล์ หรือดาวน์โหลด — ใช้ได้บน iOS)

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือเสิร์ฟด้วย `python -m http.server` แล้วเข้า `http://localhost:8000/trip-planner/`
